Gunakan database terpisah dari produksi. Jangan\nmenyalin data produksi tanpa persetujuan; gunakan data uji/anonymized. Jalankan\n`php artisan test` dengan konfigurasi MariaDB staging dan simpan hasilnya.\n\n**EXT-02 — Domain/TLS.** Siapkan subdomain, DNS, dan sertifikat. Verifikasi:\n`curl -I https://<domain>/`, redirect HTTP, `Strict-Transport-Security`,\n`Content-Security-Policy`, cookie `Secure; HttpOnly`, dan tidak ada mixed content.\nJangan menonaktifkan HTTPS untuk “sementara”.\n\n**EXT-03 — SMTP.** Gunakan relay resmi, bukan akun pribadi. Uji alur “lupa\npassword” dari akun uji sampai email masuk. Periksa tautan, masa berlaku token,\ndan header `From`. Jangan menaruh password SMTP di tiket/chat/log.\n\n**EXT-04 — Backup.** Ikuti `docs/BACKUP_RESTORE.md`. Backup remote harus di host\nterpisah; enkripsi at-rest; retensi disetujui. Uji restore ke staging, bukan hanya\nmelihat file dump. Catat durasi dan jumlah tabel/baris.\n\n**EXT-05 — Database.** Minta DBA mencatat `sql_mode`, `character_set_server`,\n`collation_server`, dan versi tepat. Jalankan migrasi dari nol di staging dan\nbandingkan dengan database lokal. Jangan mengubah migrasi lama tanpa prosedur\npengecualian di `AGENTS.md`/`docs/DECISIONS.md`.\n\n**EXT-06 — Monitoring.** Minimal: `/up`, 5xx, disk, sertifikat, backup, dan\n`failed_jobs`. Tentukan siapa menerima alert dan jam eskalasi. Uji satu alert\npalsu agar jalur notifikasi terbukti.\n\n**EXT-07 — Beban/konkurensi.** Gunakan data uji, bukan data nyata. Fokus pada\nalur login, daftar koperasi, unggah dokumen, approval, dan ekspor. Uji dua\napproval bersamaan untuk memastikan `lockForUpdate()` bekerja. Jangan menjalankan\nuji beban ke produksi tanpa jendela dan persetujuan.\n\n**EXT-08 — Sign-off.** Sign-off hanya setelah EXT-01…EXT-07 dan Q-005/Q-007/\nQ-010/Q-012 tuntas atau diterima sebagai risiko. Tanpa sign-off, status tetap\n“siap secara teknis, belum go-live”.\n\n**EXT-09 — Wilayah.** Audit read-only:\n\n```sh\nphp artisan regions:audit-cooperatives --json=/tmp/audit-wilayah.json\n```\n\nUntuk koperasi yang belum terpetakan, ekspor data yang diperlukan secara\noffline (jangan commit):\n\n```sql\nSELECT id, nama, alamat, region_id\nFROM cooperatives\nWHERE deleted_at IS NULL\n  AND (region_id IS NULL OR region_id NOT IN (\n      SELECT id FROM regions WHERE type = 'village'\n  ));\n```\n\nIsi worksheet `cooperative_id,region_code,bukti,disetujui_oleh,tanggal`. Validasi\n`region_code` ada dan bertipe desa/kelurahan. Terapkan hanya setelah backup dan\npersetujuan; lalu audit ulang. Perubahan ke `NOT NULL` baru dibuat setelah audit\nbersih.\n\n**EXT-10 — Akun/secret.** Buat akun admin pertama lewat `php artisan user:create`\n(password interaktif, tidak ditanam di kode). Pisahkan user DB aplikasi dan\nbackup. Simpan kunci enkripsi backup di luar host aplikasi. Catat pemilik dan\njadwal rotasi.\n\n## 3.
